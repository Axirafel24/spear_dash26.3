# Lunge Swap (Fabric, Minecraft 26.3)

По нажатию клавиши (по умолчанию **R**, меняется в Настройки → Управление):
1. находит в хотбаре копьё с зачарованием «Рывок» (если несколько — берёт с большим уровнем);
2. переключается на него;
3. через `ATTACK_DELAY_TICKS` тиков бьёт (как обычный клик ЛКМ);
4. через `RETURN_DELAY_TICKS` тиков возвращается на прежний слот.

Если копья нет — сообщение в чат. Если ты сам переключишь слот во время последовательности, мод не мешает.

## Как собрать .jar

Нужен **JDK 25** (например Temurin 25) — Gradle сам скачает всё остальное.

    # Windows
    gradlew.bat build
    # Linux / macOS
    ./gradlew build

Готовый файл: `build/libs/lunge-swap-1.0.0.jar` (файл с `-sources` в названии не нужен).
Положи его в папку `mods` вместе с Fabric API для 26.3.

Без установки JDK: залей папку в репозиторий на GitHub — `.github/workflows/build.yml`
соберёт jar сам (вкладка Actions → Artifacts).

## Настройки

В `src/client/java/com/lungeswap/client/LungeSwapClient.java` вверху:
- `ATTACK_DELAY_TICKS` (по умолчанию 2) — задержка перед ударом;
- `RETURN_DELAY_TICKS` (по умолчанию 5) — задержка перед возвратом на слот.

20 тиков = 1 секунда. Смена предмета сбрасывает кулдаун атаки, так что при задержке 2 тика
удар будет слабее; для полного урона увеличь `ATTACK_DELAY_TICKS`.
